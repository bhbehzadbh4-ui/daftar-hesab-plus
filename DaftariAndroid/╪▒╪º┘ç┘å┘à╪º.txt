دفتر حساب اندروید - نسخه اصلاح‌شده پروژه

این ZIP پروژه منبع است و APK آماده نصب داخل آن نیست. برای ساخت APK بدون Android Studio از GitHub Actions استفاده می‌شود.

اصلاحات این نسخه:
- تشخیص و تبدیل ارقام فارسی و عربی به ارقام قابل محاسبه در ورودی تعداد و قیمت.
- تلاش بهتر برای جدا کردن تعداد و مبلغ از گفتار؛ بعد از گفتار حتماً فیلدها را بررسی کنید.
- اصلاح Workflow ساخت APK در GitHub Actions برای آماده‌سازی Gradle و بارگذاری APK به‌عنوان Artifact.

امکانات موجود:
- اپ اندروید مستقل، SQLite محلی
- دفتر مغازه و دفتر شخصی/خانه
- ثبت هزینه، درآمد، طلب و بدهی
- محاسبه مبلغ از تعداد × قیمت واحد
- سابقه و حذف ثبت‌ها

محدودیت‌های مهم:
- گفتار فارسی هنوز از سرویس تشخیص گفتار نصب‌شده روی گوشی استفاده می‌کند و ممکن است اینترنت بخواهد؛ آفلاین بودن صدای فارسی هنوز تضمین نشده است.
- استخراج گفتار قطعی نیست؛ حتماً نام کالا، تعداد و مبلغ را قبل از ذخیره بررسی کنید.
- پشتیبان‌گیری و بازیابی داخل برنامه هنوز اضافه نشده است؛ فعلاً پیش از استفاده جدی، اطلاعات مهم را فقط روی همین گوشی نگه ندارید.
- در این محیط Android SDK/Gradle نصب نیست، بنابراین APK کامپایل و روی گوشی آزمایش نشده است. GitHub Actions باید ساخت واقعی را تأیید کند.

ساخت APK از GitHub:
1) فایل ZIP را از حالت فشرده خارج کنید.
2) محتوای پوشه DaftariAndroid را به ریشه یک مخزن GitHub آپلود کنید (نه خود پوشه به‌صورت یک فایل ZIP).
3) در مخزن، تب Actions را باز کنید.
4) گردش‌کار Build Daftari APK را انتخاب و Run workflow را بزنید.
5) پس از سبز شدن اجرای workflow، پایین صفحه نتیجه بخش Artifacts و فایل daftari-debug-apk را دانلود کنید.
6) ZIP دانلودشده را باز کنید و app-debug.apk را روی گوشی نصب کنید.
