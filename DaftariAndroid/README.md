# دفتر حساب جدید برای اندروید

- شناسهٔ نصب: `ir.behzad.daftari2` (مستقل از نسخهٔ قبلی)
- Android API حداقل 23 (Android 6 و بالاتر؛ از جمله Android 10)
- ذخیرهٔ محلی، دو دفتر مغازه و خانه، خرید/هزینه، فروش/درآمد، طلب/بدهی، ثبت گفتاری فارسی، سوابق
- خروجی و بازیابی پشتیبان JSON درون برنامه

## ساخت از طریق GitHub Actions
این پروژه را در مسیر `DaftariAndroid` استخراج و از همان پوشه `gradle :app:assembleDebug` را اجرا کنید. Workflow موجود در ریشهٔ مخزن نیز می‌تواند APK را بسازد؛ artifact خروجی باید `app-debug.apk` باشد.

## نکتهٔ اطلاعات
این نسخه به‌صورت برنامه‌ای جدا نصب می‌شود و داده‌های نسخهٔ قبلی را نمی‌خواند. نسخهٔ قبلی را حذف نکنید. امکانات پشتیبان در این نسخه برای ثبت‌های همین نسخه است.
